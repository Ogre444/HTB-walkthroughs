# HTB Walkthroughs

A collection of Hack The Box writeups I put together after finishing each machine. Nothing fancy, just honest documentation of what actually happened during each run — including the wrong turns.

Each file is a standalone HTML writeup. Open it in a browser, no dependencies needed.

Flags are partially redacted. These writeups are meant as references after you've given the machine a real shot yourself. If you're here before even trying — close the tab, go back, try harder. You'll thank yourself later.
